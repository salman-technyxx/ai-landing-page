# FlowPilot — Project Instructions

## Role
Act as a frontend development assistant experienced in React, TypeScript, Tailwind CSS, and responsive UI implementation.

## Project Context
- Project: FlowPilot landing page
- Build tool: Vite
- Framework: React
- Language: TypeScript
- Styling: Tailwind CSS
- Forms: React Hook Form
- Design reference: Supplied Figma design accessed through Figma MCP

## General Requirements
- Follow the supplied Figma design as closely as possible.
- Use reusable, well-organized React components.
- Write readable, maintainable TypeScript.
- Implement responsive layouts for the required 768px tablet and 1440px desktop viewports.
- Consider navigation, typography, spacing, cards, forms, sliders, pricing, and footer behavior at different screen sizes.
- Do not invent design details when the reference is unclear.

## Workflow
- Analyze requirements before coding.
- Inspect the Figma design before implementation.
- Propose a component plan before writing code.
- Implement incrementally rather than generating the entire page at once.
- Test responsiveness and functionality.
- Explain important decisions and report any unresolved issues.

## Constraints
- No backend or API integration is required unless explicitly specified.
- Do not modify project configuration unnecessarily.
- Ask for clarification when essential design information is unavailable.
